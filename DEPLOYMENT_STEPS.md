# Deployment checklist

1. Create a public GitHub repository named `task-management-application` under `kgirija625-netizen`.
2. Upload the contents of this project folder (including `app.py`, `requirements.txt`, `templates/`, and `static/`). Do not upload `.venv/` or `tasks.db`.
3. Choose a Flask-capable hosting provider. Check its current free-tier limits and whether the filesystem persists between restarts.
4. Set `SECRET_KEY` to a long random secret in the host's environment-variable settings.
5. Install dependencies from `requirements.txt`.
6. Configure the host's start command. For a host exposing `$PORT`, use a supported command such as `waitress-serve --host=0.0.0.0 --port=$PORT app:app` if the provider supports shell expansion; otherwise use its documented port variable syntax.
7. Ensure `TASKS_DATABASE` points to persistent storage if task data must survive restarts/redeployments.
8. Open the deployed URL and test registration, login, CRUD, search, filters, and mobile layout.
9. Submit both the GitHub repository URL and live application URL if the internship portal requests both.

**Important:** source upload does not mean the live deployment is complete. Confirm the app starts and test it in the browser before submitting. Set a real secret key and use HTTPS for public deployment.


## If the deployed site opens without styling

1. Confirm `static/style.css` and `static/app.js` are committed in the repository. The `static` folder must be next to `app.py`, not inside `templates/` or another nested project folder.
2. Confirm `templates/base.html` contains the stylesheet link generated by `url_for('static', filename='style.css', v='20261011')`.
3. Open `https://YOUR-APP-URL/static/style.css?v=20261011` in a new browser tab. It should show CSS text, not a 404 page.
4. Redeploy/restart the app and hard-refresh the page with Ctrl+Shift+R. The version query parameter helps bypass a stale cached stylesheet.
5. Upload the *contents* of the extracted ZIP to the repository root. Do not leave `app.py` inside an extra `task-management-application/` subfolder unless the host's app root is configured to that folder.
